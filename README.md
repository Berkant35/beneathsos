# BeneathSOS

Open-source, offline Flutter app that helps volunteers estimate **where** a phone trapped under
earthquake rubble most likely is — as a probability map, never as a false certainty.

- Draw the rubble footprint, measure the target's Bluetooth signal at several points,
  get 50 % / 90 % probability regions and the next best point to measure.
- "I am trapped" mode turns a phone into a beacon with one tap.

> BeneathSOS supports, and never replaces, professional search & rescue.
